# iki-ik2-converter-REUPLOAD
Este repositorio contiene el reupload y respaldo de las herramientas de conversión dedicadas a los archivos de video cinemático utilizados en los juegos clásicos de NanaOn-Sha para PlayStation. Permite a la comunidad de modding trabajar de manera eficiente en la extracción, reemplazo y restauración de las escenas de video integradas.
